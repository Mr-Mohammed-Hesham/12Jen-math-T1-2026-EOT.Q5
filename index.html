📐 القاعدة الأساسية

لجعل x² + bx + c مربعاً كاملاً:
c = (b/2)²
الناتج: (x + b/2)²
صيغة الرأس:
f(x) = a(x - h)² + k
الرأس: (h, k)
خطوات إكمال المربع:
1. اجعل معامل x² = 1
2. أضف (b/2)² للطرفين
3. اكتب على شكل مربع كامل
أمثلة:
x² + 6x + 9 = (x + 3)²
x² - 8x + 16 = (x - 4)²
